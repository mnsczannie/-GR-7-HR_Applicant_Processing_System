# -GR-7-HR_Applicant_Processing_System

**AI Usage of Each Members All Throughout this Project**


**Gurion**


Generative AI tools were used throughout the development of the HR Applicant System to boost productivity and support the development process. In the planning stage, AI helped with brainstorming features, structuring requirements, and defining the application's scope. During system design, it offered suggestions on architecture, class organization, and database interaction patterns appropriate for a C# and Windows Forms environment, all of which were reviewed and adapted to fit the project's needs. In the implementation phase, AI assisted in producing boilerplate code, UI components, event handlers, and data access logic. It also explained programming concepts, proposed fixes for errors, and recommended ways to refactor code for better clarity and maintainability. Beyond coding, AI supported documentation writing, interface improvements, and debugging. Every AI-generated output — whether code, suggestions, or content — was thoroughly reviewed, tested, and validated before being incorporated into the system. The final product reflects the developer's own design choices, hands-on implementation, and quality assurance work, with AI serving strictly as a supportive tool throughout the process.


**Ocampo**


Over the course of building out the HR module, I used AI mainly as a troubleshooting guide rather than to write everything for me. I initially mixed up which forms were really under my task, and asking AI to re-check my assignment against our spec doc helped me catch the forms I had missed. When Visual Studio kept generating empty Designer files, I used AI to walk me through the correct Class versus Windows Form setup and to explain why my pasted code wasn't showing up. I also relied on AI to interpret the Azure Connection Timeout error and guide me through the correct Encrypt setting since I'd never connected to Azure SQL before. After reviewing our Git contribution requirement, I asked AI to help me restructure my commits to be more incremental instead of one bulk dump. Lastly, I had AI cross-check my code against the capstone PDF line by line, which is how I caught the mismatched status values and missing features like the On Hold option and past-date validation on interviews.
